MÓDULO 01 // LÁMINA 05 DE 06
01

Windows bloquea scripts en PowerShell

◀ Volver al Prompt #01

Síntoma: Aparece texto rojo que dice "la ejecución de scripts está deshabilitada en este sistema (PSSecurityException)".

✓ SOLUCIÓN: Escríbele al agente: "Ejecuta Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force".
02

"Un modelo te pide esperar en el plan gratis"

◀ Volver al Prompt #01

Síntoma: En el tier gratis de Antigravity, después de varias peticiones seguidas, el modelo activo puede pedirte esperar unos minutos.

✓ SOLUCIÓN: Si un modelo te pide esperar, prueba otro modelo disponible de la lista en la barra inferior del chat (ej. Gemini Flash o Pro).
03

PATH, "winget no se reconoce" o Python abre la Store

◀ Volver al Prompt #01

Síntoma: Node/FFmpeg recién instalados no se reconocen, winget no existe, o al ejecutar python se abre la Microsoft Store.

✓ SOLUCIÓN: Cierra y reabre Antigravity para refrescar el PATH. Si falta winget, actualiza "Instalador de aplicación" en Microsoft Store. Si Python abre la Store, en Windows busca "Alias de ejecución de aplicaciones" y desactiva python.exe / python3.exe.
04

Protección de tus Cuentas y API Keys

◀ Volver al Prompt #02

Regla vital: Si subes una llave a un repositorio público, bots automatizados escanean GitHub y usan tu llave en minutos.

✓ SOLUCIÓN: Si la subiste por error, revócala de inmediato y crea otra. En tu PC van solo en .env (bloqueado por .gitignore) y en GitHub van en Settings ➔ Secrets.
