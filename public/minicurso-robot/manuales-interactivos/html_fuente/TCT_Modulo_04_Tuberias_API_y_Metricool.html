Cómo funciona YouTube API y sus 2 restricciones

En console.cloud.google.com puedes habilitar YouTube Data API v3 y obtener YT_CLIENT_ID, YT_CLIENT_SECRET y YT_REFRESH_TOKEN (youtube.upload).
⚠️ Importante (Auditoría de Google): Los proyectos nuevos de Google Cloud sin auditoría suben los videos bloqueados en Privado, y mientras la pantalla OAuth esté en modo "Testing" el refresh_token caduca cada 7 días.

💡 Si quieres publicar YouTube Shorts en Público sin auditoría de Google, usa la Vía B (Metricool Gratis).

01

¿Por qué TikTok API y YouTube API salen en Privado?

La verdad: Las apps nuevas en developers.tiktok.com y los proyectos de Google Cloud sin auditoría oficial fuerzan que los videos suban en Privado (además, en Google Cloud en modo "Testing" el refresh_token caduca a los 7 días).

✓ SOLUCIÓN: Para TikTok y YouTube sin auditoría usa Metricool Gratis (que ya es partner auditado y publica en Público) o pasa tu pantalla OAuth de Google a Producción.
02

Instagram devuelve "Media ID is not available"

Qué pasa: Cuando creas el contenedor de un Reel en Instagram Graph API, los servidores de Meta tardan de 15 a 30 segundos en procesar el video antes de permitir publicarlo.

✓ SOLUCIÓN: Nuestro script publish_social.js espera automáticamente hasta que status_code == "FINISHED" antes de llamar a media_publish.
03

Mi cuenta de Instagram no aparece en Meta API

Qué pasa: Las cuentas personales de Instagram no tienen acceso a la API de publicación automática, o faltó marcar permisos al generar el token.

✓ SOLUCIÓN: Cámbiala gratis a Cuenta de Creador o Empresa, vincúlala a tu Fan Page de Facebook e incluye pages_show_list y business_management.
04

Instagram rechaza la URL del video (Error de descarga)

Qué pasa: Instagram Graph API necesita descargar el archivo .mp4 desde una URL pública directa; si tu repositorio de GitHub está en Privado, los servidores de Meta reciben un 404.

✓ SOLUCIÓN: Asegúrate de que tu repositorio de GitHub sea Público (tus llaves siguen 100% ocultas dentro de GitHub Secrets).
