Los 3 Pasos para sacar tu API Key y Voice ID en ElevenLabs.io

PASO 1 (Sacar API Key): Entra a elevenlabs.io ➔ clic en tu perfil (abajo a la izquierda) ➔ API Keys ➔ Create API Key. Activa el permiso Text to Speech: Access y copia tu llave (sk_...).
PASO 2 (Copiar Voice ID): Ve al menú Voices ➔ elige tu voz favorita en español ➔ clic en los 3 puntitos ... ➔ Copy Voice ID (ej. pNInz6obpgDQGcFmaJgB).
PASO 3 (Guardar en .env): Pega ambos datos en tu archivo .env privado para que tu script llame a POST /v1/text-to-speech/{voice_id} con el header xi-api-key.
💡 OPTIMIZACIÓN DE CRÉDITOS: eleven_flash_v2_5 (~0.5 créditos/letra = ~20k gratis; verifica en elevenlabs.io/pricing, puede variar por plan) + caché voice_cache/ SHA-256.

ETAPA 1 // EL AGENTE GENERA PRIMERO LA VOZ Y MIDE LOS SEGUNDOS

Cuando le das un tema a tu agente, él divide el guion en 4 o 5 escenas cortas, genera el archivo de voz de cada escena con ElevenLabs o Edge-TTS y mide cuánto dura exactamente cada audio (ej. Escena 1 = 4.2s, Escena 2 = 5.1s).

ETAPA 2 // COMPONE LAS ANIMACIONES CON HYPERFRAMES (HTML + GSAP)

Usando la duración exacta de la voz, el agente maqueta las tarjetas visuales sobre Node.js 22+ respetando las Zonas Seguras (Safe Zones) de la izquierda para que ningún texto quede tapado por la interfaz de Instagram, TikTok o Shorts.

ETAPA 3 // RENDERIZA EL ARCHIVO .MP4 DIRECTO A TU CARPETA /VIDEOS

Finalmente, el agente graba la composición y ejecuta ffmpeg para entregarte un archivo videos/01_reel_automatico.mp4 (1080x1920, H.264 yuv420p + AAC) listo para subirse a tu robot de GitHub Actions.

01

El MP4 se ve negro en iPhone o WhatsApp

◀ Volver al Prompt #03

Causa: A veces algunos contenedores exportan con formato de píxel yuv444p o códec mp4v que iOS e Instagram rechazan.

✓ SOLUCIÓN: Pídele al agente: "Recodifica mi MP4 con ffmpeg usando -c:v libx264 -pix_fmt yuv420p -c:a aac".
02

ElevenLabs da error "Quota Exceeded / 401"

◀ Volver al Prompt #04

Causa: Ya consumiste los créditos gratuitos del mes o copiaste tu API Key con un espacio en blanco al final.

✓ SOLUCIÓN: Con el Prompt #04 tu script salta automáticamente a Edge-TTS (alternativa gratuita no oficial) para no detener tu producción.
03

La voz pronuncia raro una sigla o web

◀ Volver al Prompt #03

Causa: Si escribes talentocontarifa.lat o $0/mes en el guion hablado, el lector puede deletrearlo raro.

✓ SOLUCIÓN: En el texto de voz escribe cómo suena ("talento con tarifa punto lat", "cero pesos al mes") y en pantalla deja el texto visual corto.
04

La música de fondo tapa mi voz

◀ Volver al Prompt #03

Causa: Si mezclas una pista musical al 100% de volumen junto con la locución, no se distingue el mensaje.

✓ SOLUCIÓN: Dile al agente: "Ajusta el volumen de la música de fondo (BGM) al 15% (0.15) y normaliza la voz a -14 LUFS".
