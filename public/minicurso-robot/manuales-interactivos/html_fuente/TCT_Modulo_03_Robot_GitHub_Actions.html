TU PROPIO ROBOT EN GITHUB ACTIONS CON GEMINI GRATIS

¿Cómo logramos que tus videos se publiquen a las 9:00 AM, 2:00 PM y 7:00 PM aunque tu computadora esté apagada y sin pagar un VPS? Usamos GitHub Actions en un repositorio público: GitHub te presta una máquina Linux (ubuntu-latest) sin costo que despierta por reloj (cron), redacta la descripción viral con Gemini API (plan gratuito) o plantilla de respaldo, y dispara tu video en menos de 45 segundos.

PASO 0 (SI PARTES DE CERO): 1) Crea tu cuenta gratis en github.com · 2) Crea un repositorio Público llamado mi-robot-videos · 3) En tu agente ejecuta gh auth login para vincular tu PC.

name: Robot Publicador 24/7 on: schedule: - cron: '7 15 * * *' # Turno Mañana (9:07 AM CDMX) - cron: '7 20 * * *' # Turno Tarde (2:07 PM CDMX) - cron: '7 1 * * *' # Turno Noche (7:07 PM CDMX) workflow_dispatch: # Botón "Run workflow" para probar a mano permissions: contents: write # Permite actualizar estado_rotacion.json
1. SCHEDULE CRON EN MINUTO 7 (EVITA FILAS)
Los 5 campos son: Minuto Hora DíaMes Mes DíaSemana. Usamos el minuto 7 (ej. 7 15 * * *) en lugar de 0 para evitar el cuello de botella mundial de las horas en punto.
2. WORKFLOW_DISPATCH (TU BOTÓN DE PRUEBA)
Agrega el botón "Run workflow" en la pestaña Actions de tu GitHub para disparar una publicación de prueba cuando quieras sin esperar al reloj.
3. PERMISSIONS: CONTENTS: WRITE (ROTACIÓN VIVA)
Permite que el robot guarde qué video acaba de publicar en estado_rotacion.json y mantenga el repositorio activo contra la pausa de 60 días.

PASO A PASO • BÓVEDA CIFRADA DE GITHUB

Dónde se cargan los Secrets en tu Repositorio

En tu computadora las llaves viven en tu archivo .env (que nunca sube a GitHub). Para que el robot en la nube las use de forma 100% invisible dentro de tu repo público, entra a tu repositorio en github.com y sigue esta ruta:

⚙️ Settings ➔ 🔐 Secrets and variables ➔ ⚡ Actions ➔ New repository secret
• GEMINI_API_KEY (La obtienes gratis en aistudio.google.com)
• META_PAGE_TOKEN, FB_PAGE_ID, IG_USER_ID (Las veremos en el Módulo 04)
• ATAJO CON GH CLI: Tras hacer gh auth login, tu agente puede subir tus secrets por ti con gh secret set NOMBRE.
CEREBRO DEL RUNNER • GEMINI + RESPALDO

Gemini API (Plan Gratuito) + Plantilla de Respaldo

No subas tus videos con el mismo texto repetido. Nuestro script scripts/generate_caption.js lee el nombre del archivo (ej. 01_oferta_2x1.mp4) y redacta un copy persuasivo nuevo en cada turno:

MOTOR PRINCIPAL: GOOGLE GEMINI API (PLAN GRATUITO)
Con tu GEMINI_API_KEY de Google AI Studio, llama a gemini-2.5-flash (cuota diaria gratuita suficiente para tus 3 publicaciones al día).
MOTOR DE RESPALDO: PLANTILLA INTELIGENTE LOCAL
Si aún no configuras GEMINI_API_KEY o la API tarda en responder, el script genera automáticamente un copy limpio con hashtags a partir del título del video para que la publicación jamás falle.

01

La Trampa de los 60 Días sin Actividad

Qué pasa: GitHub apaga automáticamente los relojes schedule: cron si un repositorio no registra actividad en 60 días seguidos.

✓ SOLUCIÓN: Nuestro workflow actualiza automáticamente estado_rotacion.json en cada corrida, manteniendo el repo activo.
02

Por qué tu Repositorio DEBE ser Público

Qué pasa: El publicador le pasa a Meta la URL raw.githubusercontent.com del MP4; en un repo privado esa URL devuelve error 404. Además, en repos públicos GitHub Actions es gratis.

✓ SOLUCIÓN: Tu repo debe ser público (o aloja los MP4 en GitHub Releases / Cloudflare R2). Nunca pongas llaves en el código; usa siempre GitHub Secrets.
03

El cron no disparó al segundo exacto

Qué pasa: En horas en punto (:00), la cola mundial de GitHub puede tardar entre 3 y 15 minutos en asignar un runner.

✓ SOLUCIÓN: Por eso programamos nuestros crons en el minuto 7 (7 15 * * *) y para pruebas inmediatas usamos el botón Run workflow.
04

Límites de peso en GitHub (50 MB / 100 MB / ~1 GB)

Qué pasa: GitHub lanza aviso desde 50 MB por archivo, rechaza archivos >100 MB y tiene un límite blando de ~1 GB por repositorio total.

✓ SOLUCIÓN: Exporta tus Reels con -crf 20 (pesan 4–12 MB) y borra periódicamente de videos/ los MP4 viejos que ya fueron publicados.
